# WallTrace AR — прототип Android-приложения

**Назначение:** загрузить собственный эскиз и разместить его в дополненной реальности на вертикальной поверхности, чтобы при движении телефона рисунок оставался привязанным к стене.

## Уже предусмотрено в прототипе
- Русские подписи интерфейса.
- Выбор изображения из галереи/файлов Android.
- ARCore и распознавание вертикальных плоскостей.
- Размещение эскиза касанием стены.
- Настройка размера и прозрачности.
- Кнопки «Закрепить», «Разблокировать» и «Сбросить».
- Подсказки, если стена пока не распознана.

## Важно
Это **исходный прототип, не проверенная готовая сборка**. Здесь ещё предстоит проверить компиляцию, корректность ориентации изображения на разных моделях, восстановление после потери трекинга, удобство калибровки и стабильность на больших стенах. На однотонных стенах и при плохом освещении AR-трекинг может дрейфовать.

Для запуска требуется Android-телефон с поддержкой Google Play Services for AR (ARCore), камера и актуальные сервисы ARCore. Не все модели Android совместимы.

## Сборка
Откройте папку `WallTraceAR` в Android Studio. Android Studio должна иметь доступ к Android SDK и загрузке зависимостей Gradle. После успешной синхронизации выберите **Build → Build APK(s)**. Для теста используйте APK из `app/build/outputs/apk/debug/`.

## Технологии
- Java / Android SDK
- ARCore
- OpenGL ES 2.0 для вывода изображения камеры и текстуры эскиза

## Конфиденциальность
Прототип не содержит серверной части и не отправляет выбранный эскиз на сервер. Изображение загружается с устройства и отображается локально. ARCore работает через Google Play Services for AR; его собственные условия обработки данных применяются отдельно.
