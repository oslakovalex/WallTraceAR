# Как получить APK WallTrace AR через GitHub Actions

Этот проект пока не содержит готового APK. Файл `.github/workflows/build-apk.yml` добавлен, чтобы GitHub мог попробовать собрать APK в облаке.

1. На компьютере откройте https://github.com и войдите в аккаунт (если его нет — создайте).
2. Создайте новый репозиторий, например `WallTraceAR`. Для простоты можно выбрать Public.
3. Загрузите **содержимое** этой папки/архива в репозиторий так, чтобы `settings.gradle`, `build.gradle`, папка `app` и `.github` находились в корне репозитория.
4. Откройте вкладку **Actions**. Если GitHub попросит разрешить Actions, подтвердите.
5. Выберите workflow **Build WallTrace AR APK** и нажмите **Run workflow** (если сборка не стартовала автоматически после загрузки).
6. Дождитесь завершения. Зелёная галочка означает, что сборка прошла; красный крест — что нужно исправлять ошибку.
7. На странице успешного запуска внизу найдите **Artifacts** и скачайте `WallTrace-AR-debug-apk`. В архиве будет `app-debug.apk`.
8. Передайте APK на Android-телефон, откройте файл и разрешите установку из этого источника, если Android попросит.

Это автоматизация сборки, а не гарантия, что текущий исходный код уже собирается или что приложение правильно работает на телефоне. Если сборка упадёт, откройте лог шага с ошибкой или пришлите сюда скриншот/текст ошибки — помогу исправить.
